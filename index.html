      How to Link Your Calendar

      Linking Google Calendar

      1. Open Google Calendar on your computer.
      2. In the top right, click Settings > Settings.
      3. On the left sidebar, select the calendar you want to share.
      4. Scroll down to Integrate calendar.
      5. Copy the Secret address in iCal format.
      6. Paste this URL into Settings → Calendar file / link import (.ics) → ICS URL and click Load.
      Note: Use the "Secret address" to keep your calendar private while allowing this tool to access it.

      Linking Outlook Calendar

      1. Open Outlook Web (outlook.office.com).
      2. Click Settings > View all Outlook settings.
      3. Go to Calendar > Shared calendars.
      4. Under "Publish a calendar", select the calendar and permissions (e.g., "Can view all details").
      5. Click Publish.
      6. Copy the ICS link.
      7. Paste this URL into Settings → Calendar file / link import (.ics) → ICS URL and click Load.

      Linking Apple Calendar (iCloud)

      1. Open the Calendar app on iCloud.com or your Mac.
      2. Click the broadcast icon next to the calendar name.
      3. Check Public Calendar.
      4. Copy the link provided.
      5. Replace webcal:// with https:// in the URL.
      6. Paste this URL into Settings → Calendar file / link import (.ics) → ICS URL and click Load.

      About ADHD Tools Hub

      ADHD Tools Hub is a collection of interactive tools designed to help individuals with ADHD manage their symptoms, improve productivity, and enhance focus.

      Why These Tools?

      People with ADHD often struggle with executive functions like time management, organization, prioritization, and maintaining focus. The tools in this hub are specifically designed to address these challenges using evidence-based strategies.

      Features
      • Pomodoro Timer: Work in focused sprints with timed breaks to maintain productivity.
      • Day Planner: Visualize your day with time blocks for better time management.
      • Task Breakdown: Break complex tasks into smaller, manageable steps.
      • Habit Tracker: Build consistency with daily habit tracking and streaks.
      • Focus Mode: Minimize distractions with a clean, focused interface.
      • Rewards: Celebrate your accomplishments with visual rewards.

      Privacy

      All data is stored locally in your browser. Nothing is sent to any server, ensuring your information remains private.

      Feedback

      We're constantly working to improve these tools. If you have suggestions or feedback, please let us know!
